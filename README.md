# Fresa Confeitaria — Apresentação de marca

Landing page de apresentação da marca Fresa: história, conceito do nome, revelação da marca, texturas, paleta, tipografia, embalagens e redes sociais.

**Ver online:** https://olucasloboo.github.io/fresa-confeitaria/

## Tecnologia

- HTML, CSS e JavaScript estático (um único `index.html`)
- [GSAP](https://gsap.com) + ScrollTrigger para as animações de rolagem
- [Lenis](https://lenis.darkroom.engineering) para rolagem suave
- Fontes: Parkinsans, Libre Baskerville e Momo Signature (Google Fonts)
- Efeitos sonoros sintetizados com Web Audio (`assets/som.js`), desligados por padrão

## Rodar localmente

Sirva a pasta por um servidor local, por exemplo:

```bash
npx http-server -p 5173
```

e abra http://localhost:5173.
